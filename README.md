# Q-learning-Pacman

Обучение Pac-Man табличным Q-learning. Агент учится собирать точки и не попадаться призракам. Для одного, двух и трёх призраков обучается отдельная таблица.

Игра pygame, спрайты и поведение призраков классического клона написал **usawa**, лицензия GPLv3: https://github.com/usawa/pypacman. Исходники, картинки и звуки того репозитория сюда не копировались. В `train_qlearning.py` своя сетка, награды и обучение. Подробнее в `LICENSE.md`.

## Состояние и действия

Состояние совпадает со схемой курсовой работы: **192** значения.

- 8 направлений от Pac-Man к ближайшему призраку
- 8 направлений к ближайшей точке
- 3 корзины дистанции до призрака: до 2 клеток, до 5, дальше

Действия — четыре хода: вверх, вниз, влево, вправо. Ход в стену не выполняется. Призрак в 75% случаев идёт к игроку кратчайшим свободным путём, в 25% выбирает случайный свободный ход. После энерджайзера призрак убегает и на это время съеденный призрак не возвращается на поле. Игрок ходит чаще призрака.

Награда: точка **+10**, энерджайзер **+20**, съеденный призрак **+40**, очищенное поле **+80**, поимка **−80**, шаг **−0,2**, плюс небольшой бонус за приближение к ближайшей точке.

Каждая политика учится **700** эпизодов. Коэффициент обучения 0,25, дисконт 0,95, ε падает от 1 до 0,05.

## Результат

Оценка — 40 жадных партий на каждую таблицу, без исследования. Рядом указан счёт случайной политики на тех же правилах.

| Призраки | Победы | Средний счёт | Точек осталось | Случайная политика, счёт |
|---:|---:|---:|---:|---:|
| 1 | 90% | 1048 | 1,4 | 165, побед 0 |
| 2 | 22,5% | 758 | 24 | 155, побед 0 |
| 3 | 0% | 573 | 40 | 116, побед 0 |

С одним призраком поле почти всегда очищается. С двумя агент выигрывает часть партий и набирает примерно в пять раз больше случайного игрока. С тремя призраками на этой сетке полная очистка не получается: средний счёт всё равно около 573 против 116 у случайной игры.

На последних 100 эпизодах обучения доля побед была 62% для одного призрака, 9% для двух и 1% для трёх. Таблицы: `results/q_table_1.npy`, `q_table_2.npy`, `q_table_3.npy`. Сводка: `results/metrics.json`.

## Запуск

```bash
pip install -r requirements.txt
python train_qlearning.py
```
